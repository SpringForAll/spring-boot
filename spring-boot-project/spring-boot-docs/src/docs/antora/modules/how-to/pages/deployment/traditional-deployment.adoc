[[howto.deployment.traditional]]
= 传统部署

Spring Boot 应用程序可以打包为 War 文件并部署到传统的应用服务器上。

[[howto.deployment.traditional.war]]
== 创建 War 文件

要创建一个可部署的 War 文件，您需要将 Spring Boot 应用程序的打包类型更改为 `war`，并确保它有一个传统的 `web.xml` 文件。以下是一个示例 `pom.xml` 配置：

[source,xml]
----
<packaging>war</packaging>

<build>
    <plugins>
        <plugin>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-maven-plugin</artifactId>
            <configuration>
                <mainClass>com.example.MainApplication</mainClass>
            </configuration>
        </plugin>
    </plugins>
</build>
----

[[howto.deployment.traditional.convert]]
== 转换现有应用

要将现有的 Spring 应用程序转换为 Spring Boot 应用程序，您需要添加 Spring Boot 的依赖项，并确保它的配置文件与 Spring Boot 的约定相匹配。以下是一个示例 `pom.xml` 配置：

[source,xml]
----
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
----

[[howto.deployment.traditional.weblogic]]
== 部署到 WebLogic

要将 Spring Boot 应用程序部署到 WebLogic，您需要创建一个 War 文件，并将其部署到 WebLogic 服务器。以下是一个示例部署命令：

[source,shell]
----
$ java -jar wldeploy.jar -adminurl t3://localhost:7001 -username weblogic -password welcome1 -deploy -name myapp -source /path/to/myapp.war
----

确保 WebLogic 服务器正在运行，并且您有权访问它。
