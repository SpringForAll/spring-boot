[[howto.deployment.installing]]
= 安装 Spring Boot 应用程序

Spring Boot 应用程序可以作为 `systemd` 服务或 `init.d` 服务安装和管理。

[[howto.deployment.installing.systemd]]
== 使用 systemd

要将 Spring Boot 应用程序作为 `systemd` 服务运行，您需要创建一个服务单元文件。以下是一个示例：

[source]
----
[Unit]
Description=Spring Boot 应用程序
After=syslog.target

[Service]
User=springboot
ExecStart=/usr/bin/java -jar /path/to/your/app.jar
SuccessExitStatus=143

[Install]
WantedBy=multi-user.target
----

将此文件保存到 `/etc/systemd/system/your-app.service`，然后运行以下命令以启用和启动服务：

[source,shell]
----
sudo systemctl enable your-app
sudo systemctl start your-app
----

[[howto.deployment.installing.initd]]
== 使用 init.d

要将 Spring Boot 应用程序作为 `init.d` 服务运行，您需要创建一个启动脚本。以下是一个示例：

[source,shell]
----
#!/bin/sh
# /etc/init.d/your-app

case "$1" in
  start)
    echo "Starting your-app"
    /usr/bin/java -jar /path/to/your/app.jar &
    ;;
  stop)
    echo "Stopping your-app"
    kill $(cat /var/run/your-app.pid)
    ;;
  *)
    echo "Usage: /etc/init.d/your-app {start|stop}"
    exit 1
    ;;
esac

exit 0
----

将此脚本保存到 `/etc/init.d/your-app`，然后运行以下命令以启用和启动服务：

[source,shell]
----
sudo chmod +x /etc/init.d/your-app
sudo update-rc.d your-app defaults
sudo /etc/init.d/your-app start
----

确保您的应用程序在启动时创建一个 PID 文件，例如 `/var/run/your-app.pid`，以便 `stop` 命令可以正常工作。
