== 使用 Spring Security 保护 Jersey 端点

Spring Security 可用于保护基于 Jersey 的 Web 应用，与保护基于 Spring MVC 的 Web 应用方式类似。
但如果你希望在 Jersey 中使用 Spring Security 的方法级安全，则必须将 Jersey 配置为使用 `setStatus(int)` 而不是 `sendError(int)`。
这样可以防止 Jersey 在 Spring Security 有机会向客户端报告认证或授权失败之前提交响应。

必须在应用的 javadoc:org.glassfish.jersey.server.ResourceConfig[] bean 上将 `jersey.config.server.response.setStatusOverSendError` 属性设置为 `true`，如下例所示：
