[[testing.spring-applications]]
= 测试Spring应用程序

依赖注入的主要优势之一是它应该使您的代码更容易进行单元测试。
您可以使用 `new` 运算符实例化对象，甚至不需要涉及Spring。
您还可以使用模拟对象（_mock objects_）代替真实的依赖项。

通常，您需要超越单元测试并开始集成测试（使用Spring javadoc:org.springframework.context.ApplicationContext[]）。
能够在不部署应用程序或不需要连接到其他基础设施的情况下执行集成测试是很有用的。

Spring Framework包含一个专门用于此类集成测试的测试模块。
您可以直接声明对 `org.springframework:spring-test` 的依赖，或使用 `spring-boot-starter-test` starter来间接引入它。

如果您之前没有使用过 `spring-test` 模块，您应该先阅读Spring Framework参考文档中的 {url-spring-framework-docs}/testing.html[相关部分]。
