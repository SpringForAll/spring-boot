[[actuator.enabling]]
= 启用生产级特性

{code-spring-boot}/spring-boot-project/spring-boot-actuator[`spring-boot-actuator`] 模块提供了 Spring Boot 的全部生产级特性。
推荐的启用方式是添加 `spring-boot-starter-actuator` starter 依赖。

.术语解释：Actuator
****
Actuator（执行器）是制造业术语，指用于移动或控制某物的机械装置。
Actuator 能通过微小变化产生大量运动。
****

如需在基于 Maven 的项目中添加 actuator，请加入如下 starter 依赖：

[source,xml]
----
<dependencies>
	<dependency>
		<groupId>org.springframework.boot</groupId>
		<artifactId>spring-boot-starter-actuator</artifactId>
	</dependency>
</dependencies>
----

对于 Gradle，请使用如下声明：

[source,gradle]
----
dependencies {
	implementation 'org.springframework.boot:spring-boot-starter-actuator'
}
----
