[[io.validation]]
= 校验

只要 classpath 上存在 Bean Validation 1.1（如 Hibernate validator）实现，方法级校验功能会自动启用。
这允许在 bean 方法的参数和/或返回值上使用 `jakarta.validation` 约束注解。
带有此类注解方法的目标类需在类型级别加上 javadoc:org.springframework.validation.annotation.Validated[format=annotation] 注解，方法才会被扫描以查找内联约束注解。

例如，以下服务会校验第一个参数，确保其长度在 8 到 10 之间：

include-code::MyBean[]

应用的 javadoc:org.springframework.context.MessageSource[] 用于解析约束消息中的 `+{parameters}+`。
这允许你使用 xref:features/internationalization.adoc[应用的 `messages.properties` 文件] 作为 Bean Validation 消息。
参数解析后，消息插值由 Bean Validation 默认插值器完成。

如需自定义用于构建 javadoc:jakarta.validation.ValidatorFactory[] 的 javadoc:jakarta.validation.Configuration[]，可定义 javadoc:org.springframework.boot.autoconfigure.validation.ValidationConfigurationCustomizer[] bean。
如定义了多个定制器 bean，会根据其 javadoc:org.springframework.core.annotation.Order[format=annotation] 注解或 javadoc:org.springframework.core.Ordered[] 实现的顺序依次调用。
