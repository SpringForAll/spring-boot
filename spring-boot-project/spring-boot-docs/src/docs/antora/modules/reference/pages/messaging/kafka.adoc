[[messaging.kafka]]
= Apache Kafka 支持

通过对 `spring-kafka` 项目的自动配置，Spring Boot 支持 https://kafka.apache.org/[Apache Kafka]。

Kafka 的配置通过 `spring.kafka.*` 外部配置属性控制。
例如，你可以在 `application.properties` 中声明如下配置：

[configprops,yaml]
----
spring:
  kafka:
    bootstrap-servers: "localhost:9092"
    consumer:
      group-id: "myGroup"
----

TIP: 如需在启动时创建 topic，可添加类型为 javadoc:org.apache.kafka.clients.admin.NewTopic[] 的 bean。
如果 topic 已存在，则该 bean 会被忽略。

更多支持选项请参见 javadoc:org.springframework.boot.autoconfigure.kafka.KafkaProperties[]。

[[messaging.kafka.streams]]
== Kafka Streams

Spring for Apache Kafka 提供了一个工厂 bean 用于创建 javadoc:org.apache.kafka.streams.StreamsBuilder[] 对象并管理其流的生命周期。
只要 classpath 上有 `kafka-streams` 且通过 javadoc:org.springframework.kafka.annotation.EnableKafkaStreams[format=annotation] 注解启用，Spring Boot 会自动配置所需的 javadoc:org.springframework.kafka.config.KafkaStreamsConfiguration[] bean。

启用 Kafka Streams 意味着必须设置 application id 和 bootstrap servers。
前者可通过 `spring.kafka.streams.application-id` 配置，若未设置则默认为 `spring.application.name`。
后者可全局设置，也可仅为 streams 单独覆盖。

还有若干专用属性可用，其他任意 Kafka 属性可通过 `spring.kafka.streams.properties` 命名空间设置。
更多信息参见 xref:messaging/kafka.adoc#messaging.kafka.additional-properties[]。

要使用工厂 bean，可将 javadoc:org.apache.kafka.streams.StreamsBuilder[] 注入到 javadoc:org.springframework.context.annotation.Bean[format=annotation]，如下所示：

[[messaging.kafka.additional-properties]]
== 其他 Kafka 属性

自动配置支持的属性见附录 xref:appendix:application-properties/index.adoc#appendix.application-properties.integration[集成属性] 部分。
大多数情况下，这些属性（无论是连字符还是驼峰命名）都直接映射到 Apache Kafka 的点分属性。
详情请参见 Apache Kafka 官方文档。

未包含客户端类型（`producer`、`consumer`、`admin` 或 `streams`）的属性视为通用属性，适用于所有客户端。
如有需要，大多数通用属性可为一个或多个客户端类型单独覆盖。

Apache Kafka 将属性分为 HIGH、MEDIUM 和 LOW 三个重要级别。
Spring Boot 自动配置支持所有 HIGH 重要级别属性，部分 MEDIUM 和 LOW 属性，以及所有无默认值的属性。

Kafka 支持的属性中，只有一部分可通过 javadoc:org.springframework.boot.autoconfigure.kafka.KafkaProperties[] 类直接配置。
如需为各客户端类型配置更多未直接支持的属性，可使用如下属性：

[configprops,yaml]
----
spring:
  kafka:
    properties:
      "[prop.one]": "first"
    admin:
      properties:
        "[prop.two]": "second"
    consumer:
      properties:
        "[prop.three]": "third"
    producer:
      properties:
        "[prop.four]": "fourth"
    streams:
      properties:
        "[prop.five]": "fifth"
----

这会将通用的 `prop.one` Kafka 属性设置为 `first`（适用于 producer、consumer、admin 和 streams），`prop.two` 设置为 admin 属性，`prop.three` 设置为 consumer 属性，`prop.four` 设置为 producer 属性，`prop.five` 设置为 streams 属性。

你还可以如下配置 Spring Kafka 的 javadoc:org.springframework.kafka.support.serializer.JsonDeserializer[]：

[configprops,yaml]
----
spring:
  kafka:
    consumer:
      value-deserializer: "org.springframework.kafka.support.serializer.JsonDeserializer"
      properties:
        "[spring.json.value.default.type]": "com.example.Invoice"
        "[spring.json.trusted.packages]": "com.example.main,com.example.another"
----

同样，你可以禁用 javadoc:org.springframework.kafka.support.serializer.JsonSerializer[] 默认发送类型信息到 header 的行为：

[configprops,yaml]
----
spring:
  kafka:
    producer:
      value-serializer: "org.springframework.kafka.support.serializer.JsonSerializer"
      properties:
        "[spring.json.add.type.headers]": false
----

IMPORTANT: 通过这种方式设置的属性会覆盖 Spring Boot 明确支持的任何配置项。



[[messaging.kafka.embedded]]
== 使用嵌入式 Kafka 进行测试

Spring for Apache Kafka 提供了便捷方式，可通过嵌入式 Apache Kafka broker 测试项目。
要使用此功能，在测试类上添加 `spring-kafka-test` 模块中的 javadoc:org.springframework.kafka.test.context.EmbeddedKafka[format=annotation] 注解。
更多信息请参见 Spring for Apache Kafka {url-spring-kafka-docs}/testing.html#ekb[参考手册]。

要让 Spring Boot 自动配置与上述嵌入式 Apache Kafka broker 协同工作，需要将嵌入式 broker 地址（由 javadoc:org.springframework.kafka.test.EmbeddedKafkaBroker[] 提供）映射到 Spring Boot 的 Apache Kafka 配置属性。
有几种方式可以实现：

* 在测试类中通过系统属性将嵌入式 broker 地址映射到 configprop:spring.kafka.bootstrap-servers[]：

include-code::property/MyTest[tag=*]

* 在 javadoc:org.springframework.kafka.test.context.EmbeddedKafka[format=annotation] 注解上配置属性名：

include-code::annotation/MyTest[]

* 在配置属性中使用占位符：

[configprops,yaml]
----
spring:
  kafka:
    bootstrap-servers: "${spring.embedded.kafka.brokers}"
----
