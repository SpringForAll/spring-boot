[[messaging.websockets]]
= WebSockets

Spring Boot 为嵌入式 Tomcat、Jetty 和 Undertow 提供了 WebSockets 自动配置。
如果你将 war 包部署到独立容器，Spring Boot 会假定容器自身负责 WebSocket 支持的配置。

Spring Framework 为 MVC Web 应用提供了 {url-spring-framework-docs}/web/websocket.html[丰富的 WebSocket 支持]，可通过 `spring-boot-starter-websocket` 模块轻松访问。

WebSocket 支持同样适用于 {url-spring-framework-docs}/web/webflux-websocket.html[响应式 Web 应用]，此时需在 `spring-boot-starter-webflux` 之外引入 WebSocket API：

[source,xml]
----
<dependency>
	<groupId>jakarta.websocket</groupId>
	<artifactId>jakarta.websocket-api</artifactId>
</dependency>
----
