[[messaging.websockets]]
= WebSockets

Spring Boot 为嵌入式 Tomcat、Jetty 和 Undertow 提供 WebSockets 自动配置。
如果您将 war 文件部署到独立容器，Spring Boot 假定容器负责配置其 WebSocket 支持。

Spring Framework 为 MVC Web 应用程序提供了 {url-spring-framework-docs}/web/websocket.html[丰富的 WebSocket 支持]，可以通过 `spring-boot-starter-websocket` 模块轻松访问。

WebSocket 支持也可用于 {url-spring-framework-docs}/web/webflux-websocket.html[响应式 Web 应用程序]，需要包含 WebSocket API 以及 `spring-boot-starter-webflux`：

[source,xml]
----
<dependency>
	<groupId>jakarta.websocket</groupId>
	<artifactId>jakarta.websocket-api</artifactId>
</dependency>
----
