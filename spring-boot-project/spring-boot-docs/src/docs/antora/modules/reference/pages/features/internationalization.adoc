[[features.internationalization]]
= 国际化

Spring Boot 支持本地化消息，使你的应用能够满足不同语言偏好的用户。
默认情况下，Spring Boot 会在类路径根目录查找 `messages` 资源包。

NOTE: 仅当已配置资源包的默认属性文件可用（默认是 `messages.properties`）时，自动配置才会生效。
如果你的资源包仅包含特定语言的属性文件，则需要补充默认文件。
如果没有找到与任何已配置基名匹配的属性文件，则不会自动配置 javadoc:org.springframework.context.MessageSource[]。

资源包的基名以及其他属性可通过 `spring.messages` 命名空间进行配置，如下所示：

[configprops,yaml]
----
spring:
  messages:
    basename: "messages, config.i18n.messages"
    common-messages: "classpath:my-common-messages.properties"
    fallback-to-system-locale: false
----

TIP: configprop:spring.messages.basename[] 属性支持位置列表，可以是包限定名或从类路径根解析的资源。
configprop:spring.messages.common-messages[] 属性支持属性文件资源列表。

更多支持的选项请参见 javadoc:org.springframework.boot.autoconfigure.context.MessageSourceProperties[]。
