[[io.rest-client]]
= 调用 REST 服务

Spring Boot 提供了多种便捷方式用于调用远程 REST 服务。
如果你正在开发非阻塞的响应式应用，并且使用 Spring WebFlux，则可以使用 javadoc:org.springframework.web.reactive.function.client.WebClient[]。
如果你更倾向于阻塞式 API，则可以使用 javadoc:org.springframework.web.client.RestClient[] 或 javadoc:org.springframework.web.client.RestTemplate[]。



[[io.rest-client.webclient]]
== WebClient

如果你的 classpath 上有 Spring WebFlux，推荐使用 javadoc:org.springframework.web.reactive.function.client.WebClient[] 调用远程 REST 服务。
javadoc:org.springframework.web.reactive.function.client.WebClient[] 接口提供了函数式风格 API，并且完全响应式。
你可以在专门的 {url-spring-framework-docs}/web/webflux-webclient.html[Spring Framework 文档 WebClient 部分] 了解更多。

TIP: 如果你不是在编写响应式 Spring WebFlux 应用，可以使用 xref:io/rest-client.adoc#io.rest-client.restclient[`RestClient`] 替代 javadoc:org.springframework.web.reactive.function.client.WebClient[]。
这提供了类似的函数式 API，但为阻塞式而非响应式。

Spring Boot 会为你创建并预配置一个原型 javadoc:org.springframework.web.reactive.function.client.WebClient$Builder[] bean。
强烈建议在你的组件中注入它，并用来创建 javadoc:org.springframework.web.reactive.function.client.WebClient[] 实例。
Spring Boot 配置该 builder 以共享 HTTP 资源，并以与服务器相同的方式反映 codecs 设置（参见 xref:web/reactive.adoc#web.reactive.webflux.httpcodecs[WebFlux HTTP codecs 自动配置]），以及更多。

[[io.rest-client.webclient.runtime]]
=== WebClient 运行时

Spring Boot 会根据应用 classpath 上可用的库自动检测用于驱动 javadoc:org.springframework.web.reactive.function.client.WebClient[] 的 javadoc:org.springframework.http.client.reactive.ClientHttpConnector[]。
优先顺序如下，支持以下客户端：

. Reactor Netty
. Jetty RS client
. Apache HttpClient
. JDK HttpClient

如果 classpath 上有多个客户端，将使用优先级最高的客户端。

`spring-boot-starter-webflux` starter 默认依赖 `io.projectreactor.netty:reactor-netty`，它同时带来服务器和客户端实现。
如果你选择使用 Jetty 作为响应式服务器，则应添加 Jetty Reactive HTTP client 库依赖 `org.eclipse.jetty:jetty-reactive-httpclient`。
客户端和服务器使用同一技术有优势，因为会自动在客户端和服务器之间共享 HTTP 资源。

开发者可以通过提供自定义 javadoc:org.springframework.http.client.ReactorResourceFactory[] 或 javadoc:org.springframework.http.client.reactive.JettyResourceFactory[] bean 覆盖 Jetty 和 Reactor Netty 的资源配置——这会同时应用于客户端和服务器。

如果你希望为客户端覆盖该选择，可以定义自己的 javadoc:org.springframework.http.client.reactive.ClientHttpConnector[] bean，并完全控制客户端配置。

你可以在 {url-spring-framework-docs}/web/webflux-webclient/client-builder.html[`Spring Framework 参考文档 WebClient 配置选项`] 了解更多。



[[io.rest-client.webclient.configuration]]
=== 全局 HTTP Connector 配置

如果自动检测到的 javadoc:org.springframework.http.client.reactive.ClientHttpConnector[] 不能满足你的需求，可以使用 configprop:spring.http.reactiveclient.connector[] 属性选择特定 connector。
例如，如果你的 classpath 上有 Reactor Netty，但更喜欢 Jetty 的 javadoc:org.eclipse.jetty.client.HttpClient[]，可以添加如下配置：

[configprops,yaml]
----
spring:
  http:
    reactiveclient:
      connector: jetty
----

你还可以设置属性以更改所有响应式 connector 的默认值。
例如，你可能希望更改超时时间以及是否跟随重定向：

[configprops,yaml]
----
spring:
  http:
    reactiveclient:
      connect-timeout: 2s
      read-timeout: 1s
      redirects: dont-follow
----

对于更复杂的定制，可以使用 javadoc:org.springframework.boot.autoconfigure.http.client.reactive.ClientHttpConnectorBuilderCustomizer[]，或声明你自己的 javadoc:org.springframework.boot.http.client.reactive.ClientHttpConnectorBuilder[] bean，这将导致自动配置失效。
当你需要定制底层 HTTP 库的一些内部细节时，这很有用。

[[io.rest-client.webclient.customization]]
=== WebClient 定制

javadoc:org.springframework.web.reactive.function.client.WebClient[] 定制有三种主要方式，取决于你希望定制的范围。

若希望定制范围尽可能窄，注入自动配置的 javadoc:org.springframework.web.reactive.function.client.WebClient$Builder[]，然后按需调用其方法。
javadoc:org.springframework.web.reactive.function.client.WebClient$Builder[] 实例是有状态的：对 builder 的任何更改都会反映到随后用它创建的所有客户端。
如果你想用同一个 builder 创建多个客户端，也可以通过 `WebClient.Builder other = builder.clone();` 克隆 builder。

若希望对所有 javadoc:org.springframework.web.reactive.function.client.WebClient$Builder[] 实例进行应用级别的增量定制，可以声明 javadoc:org.springframework.boot.web.reactive.function.client.WebClientCustomizer[] bean，并在注入点本地更改 javadoc:org.springframework.web.reactive.function.client.WebClient$Builder[]。

最后，你可以回退到原始 API，直接使用 `WebClient.create()`。
此时不会应用自动配置或 javadoc:org.springframework.boot.web.reactive.function.client.WebClientCustomizer[]。

[[io.rest-client.resttemplate]]
== RestTemplate

Spring Framework 的 javadoc:org.springframework.web.client.RestTemplate[] 类早于 javadoc:org.springframework.web.client.RestClient[]，是许多应用调用远程 REST 服务的经典方式。
当你有现有代码不想迁移到 javadoc:org.springframework.web.client.RestClient[]，或已熟悉 javadoc:org.springframework.web.client.RestTemplate[] API 时，可以选择使用 javadoc:org.springframework.web.client.RestTemplate[]。

由于 javadoc:org.springframework.web.client.RestTemplate[] 实例通常需要在使用前定制，Spring Boot 不会提供任何单一自动配置的 javadoc:org.springframework.web.client.RestTemplate[] bean。
但会自动配置一个 javadoc:org.springframework.boot.web.client.RestTemplateBuilder[]，可用于按需创建 javadoc:org.springframework.web.client.RestTemplate[] 实例。
自动配置的 javadoc:org.springframework.boot.web.client.RestTemplateBuilder[] 确保为 javadoc:org.springframework.web.client.RestTemplate[] 实例应用合理的 javadoc:org.springframework.boot.autoconfigure.http.HttpMessageConverters[] 和合适的 javadoc:org.springframework.http.client.ClientHttpRequestFactory[]。

[[io.rest-client.resttemplate.customization]]
=== RestTemplate 定制

javadoc:org.springframework.web.client.RestTemplate[] 定制有三种主要方式，取决于你希望定制的范围。

若希望定制范围尽可能窄，注入自动配置的 javadoc:org.springframework.boot.web.client.RestTemplateBuilder[]，然后按需调用其方法。
每次方法调用都会返回一个新的 javadoc:org.springframework.boot.web.client.RestTemplateBuilder[] 实例，因此定制仅影响本次 builder 的使用。

若希望进行应用级别的增量定制，可使用 javadoc:org.springframework.boot.web.client.RestTemplateCustomizer[] bean。
所有此类 bean 会自动注册到自动配置的 javadoc:org.springframework.boot.web.client.RestTemplateBuilder[]，并应用于用其构建的所有模板。

[[io.rest-client.clienthttprequestfactory]]
== RestClient 和 RestTemplate 的 HTTP 客户端检测

Spring Boot 会根据应用 classpath 上可用的库自动检测用于 javadoc:org.springframework.web.client.RestClient[] 和 javadoc:org.springframework.web.client.RestTemplate[] 的 HTTP 客户端。
优先顺序如下，支持以下客户端：

. Apache HttpClient
. Jetty HttpClient
. Reactor Netty HttpClient
. JDK client (`java.net.http.HttpClient`)
. Simple JDK client (`java.net.HttpURLConnection`)

如果 classpath 上有多个客户端，且未提供全局配置，将使用优先级最高的客户端。



[[io.rest-client.clienthttprequestfactory.configuration]]
=== 全局 HTTP 客户端配置

如果自动检测到的 HTTP 客户端不能满足你的需求，可以使用 configprop:spring.http.client.factory[] 属性选择特定 factory。
例如，如果你的 classpath 上有 Apache HttpClient，但更喜欢 Jetty 的 javadoc:org.eclipse.jetty.client.HttpClient[]，可以添加如下配置：

[configprops,yaml]
----
spring:
  http:
    client:
      factory: jetty
----

你还可以设置属性以更改所有客户端的默认值。
例如，你可能希望更改超时时间以及是否跟随重定向：

[configprops,yaml]
----
spring:
  http:
    client:
      connect-timeout: 2s
      read-timeout: 1s
      redirects: dont-follow
----

对于更复杂的定制，可以使用 javadoc:org.springframework.boot.autoconfigure.http.client.ClientHttpRequestFactoryBuilderCustomizer[]，或声明你自己的 javadoc:org.springframework.boot.http.client.ClientHttpRequestFactoryBuilder[] bean，这将导致自动配置失效。
当你需要定制底层 HTTP 库的一些内部细节时，这很有用。
