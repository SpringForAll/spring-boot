= Spring Boot 应用打包

Spring Boot 支持多种优化部署的技术，包括 xref:packaging/native-image/index.adoc[GraalVM native images]、xref:packaging/class-data-sharing.adoc[类数据共享（Class Data Sharing）] 和 xref:packaging/checkpoint-restore.adoc[检查点与恢复]。

Spring Boot 应用可通过 xref:packaging/container-images/index.adoc[] 中介绍的方法打包为 Docker 容器。
