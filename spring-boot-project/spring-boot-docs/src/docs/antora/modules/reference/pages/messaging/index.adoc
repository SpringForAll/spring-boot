[[messaging]]
= 消息

Spring Framework 提供了丰富的功能以集成各类消息系统，从简化 JMS API 使用的 javadoc:org.springframework.jms.core.JmsTemplate[]，到支持异步接收消息的完整基础设施。
Spring AMQP 为高级消息队列协议（AMQP）提供了类似的功能集。
Spring Boot 还为 javadoc:org.springframework.amqp.rabbit.core.RabbitTemplate[] 和 RabbitMQ 提供了自动配置选项。
Spring WebSocket 原生支持 STOMP 消息传递，Spring Boot 通过 starter 和少量自动配置也支持该功能。
Spring Boot 还支持 Apache Kafka 和 Apache Pulsar。
