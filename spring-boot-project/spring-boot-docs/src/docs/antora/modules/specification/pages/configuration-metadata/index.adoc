= 配置元数据

Spring Boot jar 包包含元数据文件，提供所有受支持配置属性的详细信息。
这些文件旨在让 IDE 开发者在用户编辑 `application.properties` 或 `application.yaml` 文件时，能够提供上下文帮助和“代码补全”。

大部分元数据文件会在编译时通过处理所有带有 javadoc:org.springframework.boot.context.properties.ConfigurationProperties[format=annotation] 注解的项自动生成。
但对于特殊场景或更高级的用例，也可以 xref:configuration-metadata/annotation-processor.adoc#appendix.configuration-metadata.annotation-processor.adding-additional-metadata[手动编写部分元数据]。
