= 配置元数据

Spring Boot jars 包含提供所有支持的配置属性详细信息的元数据文件。
这些文件旨在让 IDE 开发者在用户使用 `application.properties` 或 `application.yaml` 文件时提供上下文帮助和"`代码补全`"。

元数据文件的大部分内容是在编译时通过处理所有用 javadoc:org.springframework.boot.context.properties.ConfigurationProperties[format=annotation] 注解的项目自动生成的。
但是，对于特殊情况或更高级的用例，可以 xref:configuration-metadata/annotation-processor.adoc#appendix.configuration-metadata.annotation-processor.adding-additional-metadata[手动编写部分元数据]。
