= Spring Boot

Spring Boot 帮助您创建独立运行、生产级别的基于 Spring 的应用程序，您可以直接运行这些应用程序。
我们对 Spring 平台和第三方库采取了明确的观点，以便您可以以最小的麻烦开始使用。
大多数 Spring Boot 应用程序需要的 Spring 配置非常少。

您可以使用 Spring Boot 创建可以通过 `java -jar` 启动的 Java 应用程序，或采用更传统的 WAR 部署方式。

我们的主要目标是：

* 为所有 Spring 开发提供一个更快、更易于访问的入门体验。
* 开箱即用具有明确的设计理念，但在需求开始偏离默认设置时，能够快速适应。
* 提供一系列适用于大型项目的非功能性特性（例如嵌入式服务器、安全性、指标、健康检查和外部化配置）。
* 绝对不生成代码（当不针对原生镜像时）且无需 XML 配置。
