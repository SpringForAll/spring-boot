[[getting-started.system-requirements]]
= 系统要求

Spring Boot {version-spring-boot} 至少需要 https://www.java.com[Java 17]，并兼容最高至 Java 24。
还需要 {url-spring-framework-docs}/[Spring Framework {version-spring-framework}] 或更高版本。

以下构建工具提供了明确的支持：

|===
| 构建工具 | 版本

| Maven
| 3.6.3 或更高

| Gradle
| Gradle 7.x（7.6.4 或更高）或 8.x（8.4 或更高）
|===



[[getting-started.system-requirements.servlet-containers]]
== Servlet 容器

Spring Boot 支持以下内嵌 Servlet 容器：

|===
| 名称 | Servlet 版本

| Tomcat 10.1（10.1.25 或更高）
| 6.0

| Jetty 12.0
| 6.0

| Undertow 2.3
| 6.0
|===

你也可以将 Spring Boot 应用部署到任何兼容 Servlet 5.0+ 的容器。



[[getting-started.system-requirements.graal]]
== GraalVM Native Images

Spring Boot 应用可使用 GraalVM {version-graal} 或更高版本 xref:reference:packaging/native-image/introducing-graalvm-native-images.adoc[转换为 Native Image]。

镜像可通过 https://github.com/graalvm/native-build-tools[native build tools] Gradle/Maven 插件或 GraalVM 提供的 `native-image` 工具创建。
你也可以使用 https://github.com/paketo-buildpacks/native-image[native-image Paketo buildpack] 创建 native image。

支持以下版本：

|===
| 名称 | 版本

| GraalVM Community
| {version-graal}

| Native Build Tools
| {version-native-build-tools}
|===
