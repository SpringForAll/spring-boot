[[getting-started.system-requirements]]
= 系统要求

Spring Boot {version-spring-boot} 至少需要 https://www.java.com[Java 17]，并兼容最高到 Java 24 的版本。
同时需要 {url-spring-framework-docs}/[Spring Framework {version-spring-framework}] 或更高版本。

以下构建工具提供明确的构建支持：

|===
| 构建工具 | 版本

| Maven
| 3.6.3 或更高版本

| Gradle
| Gradle 7.x（7.6.4 或更高版本）或 8.x（8.4 或更高版本）
|===



[[getting-started.system-requirements.servlet-containers]]
== Servlet 容器

Spring Boot 支持以下嵌入式 Servlet 容器：

|===
| 名称 | Servlet 版本

| Tomcat 10.1（10.1.25 或更高版本）
| 6.0

| Jetty 12.0
| 6.0

| Undertow 2.3
| 6.0
|===

您还可以将 Spring Boot 应用程序部署到任何兼容 Servlet 5.0+ 的容器上。



[[getting-started.system-requirements.graal]]
== GraalVM 原生镜像

Spring Boot 应用程序可以使用 GraalVM {version-graal} 或更高版本 xref:reference:packaging/native-image/introducing-graalvm-native-images.adoc[转换为原生镜像]。

可以使用 https://github.com/graalvm/native-build-tools[原生构建工具] 的 Gradle/Maven 插件或 GraalVM 提供的 `native-image` 工具创建镜像。
您还可以使用 https://github.com/paketo-buildpacks/native-image[原生镜像 Paketo 构建包] 创建原生镜像。

支持以下版本：

|===
| 名称 | 版本

| GraalVM Community
| {version-graal}

| Native Build Tools
| {version-native-build-tools}
|===
